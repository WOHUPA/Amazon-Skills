# 视觉设计系统

## Design Read 与参数

> 面向中国 Amazon 卖家和运营团队的高密度、证据优先 B2B 报告，视觉严肃、现代、有 Amazon 识别度，采用语义化 HTML、原生 CSS 和内联 SVG。

- `DESIGN_VARIANCE=5`：布局有明显变化，但不干扰数据扫描。
- `MOTION_INTENSITY=2`：仅主题、目录、折叠和操作反馈；遵循 `prefers-reduced-motion`。
- `VISUAL_DENSITY=7`：适合业务报告，同时保留清晰留白和触控目标。

`taste-skill` 只约束报告外壳、首屏、节奏、主题、形状一致性和反模板化。表格、图表、CJK 字体、响应式与无障碍遵循 `frontend-design` 和组件数据契约。此 Skill 是静态报告渲染器，不采用 taste-skill 针对营销页建议的 React、Tailwind 或 Motion。

## 色彩、形状和排版

机器可读值在 `assets/visual-tokens.json`。

- Amazon 橙是唯一装饰性强调色。
- 蓝只表示链接/信息；红、绿、黄只表示真实错误、成功、警告状态。
- 内容容器圆角 12px、控件 8px、状态标签全圆角；不混用无规则几何。
- 首屏左对齐或非对称分栏；禁止通用居中巨型标题。桌面 H1 40–56px，移动端降级，不能裁切。
- 中文报告使用本地系统 CJK 字体栈；不加载 Google Fonts 或远程字体。
- 全页主题锁定，不在章节间反转明暗。首次 `system` 跟随系统，允许手动 light/dark，打印始终浅色。

## 反模板化规则

禁止 AI 紫色、发光边框、无意义渐变、连续三等分卡片、满页 eyebrow、装饰性编号/状态点、巨型 H1、假截图、假产品图和占位图片。卡片只表达真实层级；普通章节使用留白、分组、轻边界和版式变化。

模板自有 UI 文案不用长破折号；上游引文、业务证据与结论原文不得因此改写。Progress Bar 只用于真实占比/完成度。Amazon 橙不承担状态含义。

## 安全、响应式与可访问性

- 使用语义化 HTML、skip link、唯一 H1/ID、可见 focus、合理 heading 顺序。
- 表格必须有 caption 与 scope；5 列以上，或 4 列且存在加宽列的内容密集表，必须在自身键盘可达容器内横向滚动；14 列以上继续使用密集表。页面根级不得横向溢出。
- 业务数据表、图表数据摘要、雷达对比表、关键词表和来源附录统一审核整列表头及全部已格式化单元格的可见文本，隐藏来源说明不参与计宽。中文及 Unicode 全角字符计 1 个视觉单位，半角英文、数字和符号计 0.5，组合符与控制字符计 0。
- 整列最大值 `≤10` 时按内容收紧并保持单行；`>10` 时按 `min(48, max(16, 4 × ceil((最大视觉单位 + 2) / 4)))em` 分档加宽。超过 48em 容量的内容在 48em 列内换行，不能截断、省略或隐藏原值，也不能用全表 `nowrap` 制造无限宽页面。
- `序号 / 编号 / 排名 / 排行 / 名次` 等短标识列在所有值不超过 6 个视觉单位时继续紧凑展示，不得继承首列的大宽度。
- 打印端取消动态最小列宽和屏幕端单行约束，恢复自适应列宽与换行，避免超宽列扩展打印页。
- SVG 图表包含 title、desc 和文本数据摘要；颜色不是唯一编码。
- 图片必须有 alt；证据比较的标签与 caption 可打印。
- 断点至少覆盖 1440×900、768×900、390×844；显式检查浅色、深色与打印。
- JavaScript 仅渐进增强。禁用 JavaScript 时正文、来源、限制与数据摘要仍可读。
- 严格 CSP，不使用 inline event handler，不发起 fetch、XHR、WebSocket 或其他网络请求。

## 回到顶部

每份报告都必须提供“回到顶部”链接，包括 COMPLETE、PARTIAL、BLOCKED 与 DEMO 页面。它属于页面导航，不是装饰按钮或 JavaScript 功能。

- 页面顶部提供稳定且唯一的 `id="report-top"`；控件使用原生 `<a href="#report-top">` 和明确的中文可访问名称。
- 基础 HTML/CSS 状态下控件可见、可聚焦、可点击，禁用 JavaScript 仍能完成导航。不得依赖 click handler、脚本滚动 API 或客户端路由。
- JavaScript 只做渐进显隐：用 `IntersectionObserver` 观察报告首屏，在首屏可见时隐藏、离开首屏后显示。脚本失败时回退到始终可见的原生链接。
- 禁止 `scroll` 事件轮询、定时器轮询、内联事件处理器、正 `tabindex` 和鼠标专属交互。
- 控件保持正常 Tab 顺序，具有清晰 `:focus-visible`，触控目标至少 44×44 CSS px；固定定位时不得遮挡正文、表格横向滚动条、主题控件或移动端安全区域。
- 若启用平滑滚动，只能作为 CSS 增强；`prefers-reduced-motion: reduce` 下必须恢复即时滚动，且焦点不能被隐藏、重置或困在控件上。
- `@media print` 中使用 `display: none !important` 隐藏控件，不占据打印空间。
- `#report-top` 不得与 heading、组件或自动生成 ID 冲突；静态审计必须验证目标存在且唯一。

## 视觉 QA

静态检查：单一装饰强调色、主题锁、圆角规则、无未解析占位符、无外部资源、无装饰编号、无通用三卡模板、模板文案标点合规；同时检查唯一 `#report-top`、原生 `href="#report-top"`、打印隐藏规则、无 inline click/scroll 轮询。

截图检查：桌面/平板/手机的 light/dark/print；重点核对首屏层级、10/10.5/11 与 20/21 视觉单位边界、CJK 与混合文本列宽、48em 封顶换行、4/5/14 列布局、来源附录、表内滚动、图表标签、证据图、目录、页面根级溢出、键盘焦点、禁用 JavaScript和控制台。移动端必须同时记录 layout viewport 与 visual viewport，确认 390×844 已真实应用，不能只用旧文档的 `readyState` 或 layout viewport 误判。回到顶部还需检查顶部时不干扰阅读、滚动后显现、键盘可达、焦点可见、reduced-motion 无强制动画、禁用 JavaScript 仍可用且打印完全隐藏。
