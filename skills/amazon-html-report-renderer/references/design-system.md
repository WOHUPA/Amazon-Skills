# Design System

## 视觉设计系统

- 单一 Amazon 橙主色 `#FF9900`，深色 `#E47911`；无第二装饰色。
- 圆角：内容 12px、控件 8px、状态 999px。
- 字体栈：系统字体 + 中文回退（Microsoft YaHei / PingFang SC / Noto Sans CJK SC）。
- 浅色/深色双主题由 `prefers-color-scheme` 自动切换，页面锁定单一主题，不允许 section 级反色。
- 打印固定浅色主题，隐藏装饰元素与“回到顶部”控件。
- `prefers-reduced-motion: reduce` 下禁用非必要动画与平滑滚动。

## Taste 边界

- 禁止：紫罗兰/靛蓝系配色、渐变滥用、霓虹、玻璃拟态、渐变文字、装饰性 3D。
- 禁止：section 编号徽标、装饰性 eyebrow、三列卡片“最佳实践”套件。
- 密度：高密度数据报告；留白服务可读性，不服务“高级感”。
- 动效：极少量渐进增强，不抢数据注意力。

## 可访问性

- 语义化 HTML5；单一 `<h1>`；正确 heading 层级。
- SVG 图表必须带 `<title>` 与 `<desc>`。
- 图片必须带 alt。
- 表格有 `<caption>` 或 `aria-label`。
- 控件可达：键盘焦点可见、触控目标 ≥ 44px、正常 Tab 顺序。
- “回到顶部”为原生 `<a href="#report-top">`，无 JS 可用；JS 仅 IntersectionObserver 渐进显隐。
- 内容密集表格横向滚动仅在键盘可达的表格容器内，页面根级禁止横向溢出。

## 表格列宽规则

- 中文及 Unicode 全角字符计 1 个视觉单位，半角字符计 0.5，组合符与控制字符计 0。
- 扫描表头与整列全部已格式化可见单元格；隐藏来源说明不参与计宽。
- 整列最大值 ≤ 10 保持紧凑；> 10 按 `min(48, max(16, 4 × ceil((最大视觉单位 + 2) / 4)))em` 分档加宽。
- 超过 48em 容量后在封顶列内换行；原文不截断、不省略、不隐藏。
- 5 列以上或 4 列含加宽列进入宽表；14 列以上进入密集表。
