# Listing 优化流程

用于把标题、五点、A+、图片和关键词埋词优化流程沉淀为 skill。

## 适用场景

- 用户想做“Listing 优化 skill”“标题五点改写 skill”“竞品文案拆解 skill”。
- 用户输入 ASIN、目标关键词、竞品 ASIN 或现有 Listing 文案。
- 用户希望输出可直接交给运营修改的文案和检查清单。

## 输入

- 站点和类目。
- 目标 ASIN 或现有 Listing 文案。
- 核心关键词和长尾关键词。
- 竞品 ASIN：可选。
- 品牌语气、禁用词、合规要求。

## 推荐 MCP 组合

- SellerSprite：用 `asin_detail` 读取 ASIN 基础详情和 Listing 质量相关信息；用 `review` 抽取用户痛点；用 `keyword_research_trends` 或 `aba_research_trend` 验证关键词价值。
- Sorftime：用 `keyword_detail` 和 `keyword_search_results` 查关键词竞争页面；用 `product_ranking_trend_by_keyword` 验证目标词下 ASIN 曝光趋势。
- SIF：用 `market_get_keyword_history` 判断关键词搜索量和集中度，避免把低需求词放到高权重位置。

## 工作流

1. 收集现有 Listing：标题、五点、描述、A+、图片信息和关键词清单。
2. 建立关键词分层：核心主词、功能词、场景词、属性词、竞品词。
3. 竞品拆解：价格、评分、卖点、差评、图片表达、关键词覆盖。
4. 差评归因：从评论中提炼尺寸、材质、安装、包装、使用场景等问题。
5. 生成优化方案：标题、五点、A+ 模块、图片脚本和后台搜索词建议。
6. 做合规检查：避免医疗功效、绝对化承诺、侵权词、平台敏感表达。

## 判断规则

- 标题优先放核心主词、品牌、关键属性，不为堆词牺牲可读性。
- 五点每条只讲一个主卖点，并包含证据或使用场景。
- 差评高频问题必须转成改进建议或预期管理文案。
- 搜索量低、转化集中度高的词不要强行放标题前部。
- 图片建议必须对应买家决策问题：尺寸、场景、对比、安装、材质、包装。
