# 关键词广告流程

用于把关键词调研、自然排名追踪、广告结构诊断、出价策略和否词流程沉淀为 skill。

## 适用场景

- 用户想做“关键词排名周报 skill”“广告异常预警 skill”“关键词广告优化 skill”。
- 用户输入 ASIN、关键词、campaign ID、广告组 ID 或周日期，需要固定诊断流程。
- 用户需要把 SIF、Sorftime、SellerSprite 的关键词数据组合成报告。

## 输入

- 站点：默认 US。
- ASIN：至少 1 个。
- 核心关键词：建议 5-30 个。
- 时间范围：周报默认最近完整自然周；SIF 周数据要求周日作为起始日。
- 广告对象：campaign ID、ad group ID，可选。
- 目标：拉排名、控 ACoS、扩词、否词、诊断异常。

## 推荐 MCP 组合

- SIF：用 `market_get_keyword_history` 看搜索量和集中度；用 `ads_get_campaign_contribution_breakdown` 拆 campaign 关键词或广告组贡献；用 `ads_get_ad_group_keyword_breakdown` 拆广告组关键词。
- Sorftime：用 `product_ranking_trend_by_keyword` 看 ASIN 在关键词下的曝光排名趋势；用 `keyword_detail` 和 `keyword_trend` 补充关键词热度。
- SellerSprite：用 `keyword_research_trends` 和 `aba_research_trend` 做关键词趋势校验。

## 工作流

1. 确认目标：排名追踪、广告架构诊断、扩词、否词或出价优化。
2. 建立关键词池：核心词、长尾词、竞品词、品牌词分组。
3. 查询需求：搜索量、ABA 排名、趋势、Top3 点击/转化集中度。
4. 查询排名：自然位、广告位、排名波动，识别上升/下滑词。
5. 查询广告结构：campaign 和 ad group 的关键词贡献、流量占比、变化率。
6. 输出策略：加词、降价、提价、否词、拆组、保守观察。

## 判断规则

- 自然排名波动 ±5 位以内：正常波动。
- 自然排名下滑 5-10 位：预警，观察是否连续 2 周。
- 自然排名下滑 >10 位或掉出前 20：危险，建议人工介入。
- CTR < 0.3%：优先检查主图、标题和搜索词匹配度。
- CVR < 5%：优先检查价格、评论、Listing 说服力。
- ACoS 新品期 >70% 或成熟期 >40%：默认进入广告异常清单。
- 搜索量高但 Top3 点击占比 >0.6：扩词前先判断是否被头部垄断。

```markdown
- 检查关键词数：
- 排名异常：
- 广告异常：
- 优先动作：

| 关键词 | 搜索量 | 自然排名 | 广告贡献 | 趋势 | 建议 |

| Campaign/Ad Group | 主要问题 | 证据 | 建议动作 |

## 否词/扩词清单
| 类型 | 关键词 | 原因 | 操作 |

## 下周跟踪项
1.
2.
3.
```
