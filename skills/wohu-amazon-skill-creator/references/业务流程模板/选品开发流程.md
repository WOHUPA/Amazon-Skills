# 选品开发流程

用于把亚马逊新品开发、市场调研、竞品分析、利润测算和风险判断流程沉淀为 skill。

## 适用场景

- 用户想做“选品分析 skill”“新品可行性分析 skill”“类目机会判断 skill”。
- 用户输入类目关键词、竞品 ASIN、目标市场或成本信息，希望形成可重复评估流程。
- 用户提到 Sorftime、SIF、SellerSprite 中任一工具，并希望把多工具查询组合固定下来。

## 输入

- 目标站点：默认 US，用户可指定 JP、UK、DE、CA 等。
- 类目关键词或产品词：1-10 个。
- 竞品 ASIN：可选，建议 3-10 个。
- 成本信息：产品成本、头程、FBA 费用、目标售价、目标毛利率。
- 风险偏好：保守、均衡、激进。

## 推荐 MCP 组合

- Sorftime：用 `keyword_detail` 看关键词详情，用 `keyword_trend` 看搜索量、搜索排名和 CPC 趋势，用 `keyword_search_results` 看自然位产品清单。
- SIF：用 `market_get_keyword_history` 查询关键词搜索量、ABA 排名、Top3 点击/转化集中度。
- SellerSprite：用 `asin_detail` 或 `asin_detail_with_coupon_trend` 做竞品详情拆解，用 `bsr_prediction` 估算销量，用 `keyword_research_trends` 或 `aba_research_trend` 验证关键词趋势。

## 工作流

1. 明确目标市场、目标关键词、竞品 ASIN 和利润目标；缺任何一项先补问。
2. 用关键词数据判断需求规模：搜索量、ABA 排名、趋势、CPC、点击集中度。
3. 用竞品 ASIN 判断竞争强度：价格、评分、评论数、Listing 质量、优惠价格、BSR 预测销量。
4. 做利润测算：售价 - 平台费用 - FBA 费用 - 头程 - 产品成本 - 广告预留。
5. 做风险检查：侵权、季节性、头部垄断、评分门槛、物流尺寸、变体复杂度。
6. 给 Go / No-Go / Watchlist 结论，并列出下一步验证动作。

## 判断规则

- Top3 点击占比 > 0.6：默认判定流量高度集中，新品进入难度高。
- 评分均值 ≥ 4.3 且评论数普遍较高：需要差异化或价格优势。
- 预计净利率 < 15%：默认 No-Go，除非用户明确接受低利润冲量。
- 关键词趋势连续下滑 3 期以上：标记需求衰退风险。
- 头部竞品长期大额 Coupon：标记价格战风险。
