# Patch Log

## [2026-07-21] v2.3.0

- 将 Generator 收敛为 Theme Pack v2 构建与静态验证入口，移除 Studio 安装、更新、导入、激活和运行时验证职责。
- 将 Codex Theme Studio 迁为独立源码与安装包；Generator 不再携带 `tool/codex-theme-studio`。
- 实验布局仅只读查询已安装 Studio 的受信任宿主矩阵；Studio 缺失或矩阵非 `COMPLETE` 时阻断。
- 输出新增 `packStatus/studioDetected/handoffStatus/importStatus/activationStatus/notRun`，禁止把静态完成冒充导入或激活成功。
- 移除客户端刷新、旧主题迁移和视觉门禁回归依赖，更新 Golden Set 防止三层职责重新耦合。

## [2026-07-21] v2.2.1

- 将当前 Windows Codex 任务页的稳定数据标记纳入精确版本适配器，结构签名不再依赖缺失的 `role=main`。
- 新增 `iconSlotAlternates.send.stop` 契约，明确区分空闲发送态与流式停止态，并验证互斥性、唯一性和命中区。
- 修复主题图标在主动作节点切换时未恢复原生 SVG 的残留问题。
- 修复侧栏可见 resize handle 被 `scrollWidth` 误判为裁切；真实 `hidden/clip` 裁切仍为硬阻断。
- 新增流式任务 fixture 红测，并把 `streaming-stop` 纳入视觉回归语义状态矩阵。

## [2026-07-21] v2.2.0

- 消灭 `PARTIAL` 假绿灯：静态验证、实时验证、视觉门禁和发布语义只接受 `COMPLETE`。
- 新增精确 Codex 版本、组件构建号与结构签名组成的受信任宿主适配器；未知版本安全降级 `native` 并阻断发布。
- 新主题和 12 个内置主题统一为 `native/240/920/0/comfortable`；高级布局保留为实验能力，矩阵未全绿时拒绝生成。
- 新增按场景组件契约、图标期望、重叠/裁切/越界/横向溢出/尺寸生效审计，以及按钮、菜单、输入区、侧栏、浮层状态证据。
- 新增 PR 与发布视觉矩阵和四件套证据门禁；缺少任意证据时至少为 `PARTIAL` 且不可发布。
- 新增 Theme Pack 到官方 `codex-theme-v1:` 数据载荷的确定性编译器。
- 原生编译改用 Codex 26.715 的真实 `codex` 代码主题、60/45 contrast、null 字体与 diff 默认种子；静态验证会重编译并拒绝缺失或分叉的原生载荷。
- 语义状态证据改为按场景分配并在交互过程中累计计算样式；证据采集模式下缺状态不会提前成功。
- 语义图标覆盖原生 SVG 的既有矩形并保留布局槽，避免图标加文字按钮发生尺寸漂移或文字覆盖。

## [2026-07-21] v2.1.1

- 修复任务页将长对话直接叠在高细节背景上的可读性缺陷；新增由运行时强制控制的正文阅读层，深色最低 84% 画布遮罩、浅色最低 90%。
- 阅读层只命中版本化 DOM adapter 的精确线程列，不扩大 Theme Pack 的 CSS/selector 权限，也不改变首页背景展示。
- 将实机视觉验收从“注入成功”中独立出来，要求正文、运行记录、输入区和右侧面板在真实截图中均可辨读。

## [2026-07-21] v2.1.0

- 新增参考 CC Switch 的独立 WPF 视觉控制中心：主题卡片、搜索、深浅筛选、预览、激活、验证、回退与官方恢复。
- 内置主题仓库扩展为三套默认主题和九套斗破主题；迁移过程强制校验原背景 SHA-256，首页与任务页保持原图字节不变。
- 修复高级布局误改侧栏父级 flex-basis 导致侧栏高度塌缩的问题，并把高级布局变更限制在 adapter 自有节点。
- 修复浅色 Theme Pack 在深色原生 token 下文字和面板对比失效的问题，统一映射 Codex 语义前景、背景、边框、菜单与输入 token。
- 增加已连接 CDP 会话的快速切换路径，避免每次激活都重启 watcher；失败仍保留原事务回退。
- 受管预设改为扫描全部合法 v2 目录并原子更新，用户导入主题保持拒绝覆盖。

## [2026-07-21] v2.0.0

- 升级为唯一新主题创建入口，采用纯数据 Theme Pack v2。
- 增加双模式独立 ID、首页/任务页背景、八个语义图标、完整 palette/materials、四种白名单布局和严格兼容字段。
- 新增原子生成、恶意 SVG/路径逃逸/布局越界测试、旧 v1 迁移器和三个示范主题。
- 内置独立 Codex Theme Studio，运行时、主题、状态、备份和日志统一迁移到 `%LOCALAPPDATA%\CodexThemeStudio`。
- 修复旧 renderer 动态移动首页 prompt 的契约冲突；DOM 不匹配时高级布局降级 `native`。

- 增加固定主题 schema、静态 HTML 预览、对比度验证与图片规格校验。
- 增加正反例、触发评测和标准库单元测试。
