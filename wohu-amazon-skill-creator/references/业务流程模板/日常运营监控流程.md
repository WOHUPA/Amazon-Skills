# 日常运营监控流程

用于把每日、每周、每月运营巡检流程沉淀为 skill，覆盖销量、广告、库存、差评、排名和利润异常。

## 适用场景

- 用户想做“每日运营巡检 skill”“库存预警 skill”“差评预警 skill”“广告异常日报 skill”。
- 用户需要固定检查清单、异常阈值和报告格式。
- 用户把数据从 MCP、Excel、CSV、飞书表格或人工粘贴提供给 Codex。

## 输入

- 站点、品牌、ASIN 清单。
- 时间范围：日报、周报、月报。
- 数据来源：MCP、Excel/CSV、飞书表格、人工粘贴。
- 关注模块：销量、广告、库存、评论、排名、利润。
- 通知渠道：终端、Markdown 文件、飞书消息、表格。

## 推荐 MCP 组合

- SellerSprite：用 `asin_detail`、`review`、`asin_coupon_trend` 或 `asin_detail_with_coupon_trend` 做 ASIN、评论、价格和促销监控。
- Sorftime：用 `product_ranking_trend_by_keyword`、`keyword_trend` 监控关键词排名与搜索趋势。
- SIF：用 `market_get_keyword_history` 监控关键词需求变化；用广告拆解工具定位广告异常来源。

## 工作流

1. 确认巡检频率：每日、每周或每月。
2. 读取 ASIN、关键词、广告对象和库存数据。
3. 按模块计算异常：销量、广告、库存、评论、排名、利润。
4. 给异常分级：正常、预警、危险。
5. 只对异常项给行动建议；正常项用摘要带过。
6. 输出报告、异常清单和完成信号。

## 判断规则

- 库存可售天数 <14 天：危险；14-30 天：预警；30-60 天：健康。
- 评分 <4.0：危险；4.0-4.3：预警；≥4.3：健康。
- 差评率 >10%：危险；5-10%：预警；<5%：健康。
- 自然排名下滑 >10 位：危险；5-10 位：预警；±5 位以内正常。
- ACoS 新品期 >70% 或成熟期 >40%：危险。
- 节假日、Prime Day、黑五和新品期要单独标注，避免和普通周期硬比。

## 输出格式

```markdown
# [品牌/店铺] 运营巡检报告 (YYYY-MM-DD)

## 摘要
- 检查 ASIN：
- 预警项：
- 危险项：
- 今日优先动作：

## 异常清单
| 级别 | ASIN/对象 | 指标 | 当前值 | 阈值 | 建议动作 |

## 模块明细
### 销量
### 广告
### 库存
### 评论
### 排名

## 已完成
已完成巡检，预警 N 个，危险 M 个，报告保存到 [路径/渠道]。
```
